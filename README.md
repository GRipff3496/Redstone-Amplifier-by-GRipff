# Redstone Amplifier

![Minecraft](https://img.shields.io/badge/Minecraft-1.21-0ea5e9?style=flat)
![Forge](https://img.shields.io/badge/Forge-26.3-f59e0b?style=flat)
![License](https://img.shields.io/badge/License-MIT-green?style=flat)

**A redstone component that multiplies or divides incoming signal strength without delay.**

## Features

| Feature | Description |
| :--- | :--- |
| **Signal Amplification** | Multiplies input redstone signal by configurable factors (×2, ×3, ×5, ×10). |
| **Signal Division** | Can also divide the input signal to reduce its strength. |
| **No Delay** | Updates instantly, unlike repeaters. |
| **Configurable** | Multipliers are adjustable via Forge config. |
| **Visual Feedback** | Redstone particles and sounds indicate the current state. |

## Usage

| Action | Result |
| :--- | :--- |
| **Right-click** | Cycles through multiplier positions (0–3). |
| **Shift + Right-click** | Toggles between Multiply and Divide mode. |

The block has a dedicated **input** and **output** side. The input side is the opposite of the block's facing direction.

## Installation

1. Install Minecraft Forge for the appropriate version.

3. Place the `.jar` into your `.minecraft/mods/` folder.
4. Launch the game.
